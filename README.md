# kwinta.pro

Strona „coming soon" dla domeny kwinta.pro, publikowana przez GitHub Pages z gałęzi `main`.
Żeby zmienić treść, wyedytuj `index.html` i wypchnij zmiany na `main`; strona przebuduje się sama.
DNS domeny jest w panelu OVHcloud (rekordy `A` dla `@` wskazują na GitHub Pages, `www` to `CNAME`).
